# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest
published version and the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature on this repository instead.

Include a minimal reproduction, affected protocol, runtime version, and the
security impact. Reports involving request smuggling, message framing,
cross-request data exposure, denial of service, TLS, or CONNECT handling are
especially useful.

You can expect an initial acknowledgement within seven days. A fix and public
advisory will be coordinated after the issue is reproduced and scoped.
